听见 · 中文音乐工作台

本机：MacBook Air / Apple M5 / 16 GB 统一内存。
音乐：YuE2 MLX，Fast 8-bit，低内存模式，10 GiB 内存预算。
对话：本机 Hermes 代理，当前模型 gpt-6.1-sol（使用已有 Codex 登录）。
封面：Hermes 的 OpenAI Codex 图片后端，GPT Image 2 Low，已通过真实生成验证。

启动和停止
1. 双击“启动 YuE2.command”，打开 http://127.0.0.1:8765/。
   会复用本目录已运行的音乐服务和专用助手，不重复启动。
   新启动音乐服务时请保留终端窗口；Control-C 只停止音乐服务。
2. 助手在后台独立运行。双击“停止助手.command”可停止本工作台的助手。
   停止脚本核验进程、脚本路径与配置归属，不结束其他 Hermes 或其他应用。
3. 音乐服务只监听127.0.0.1:8765，助手只监听127.0.0.1:8642。
   若其他程序占用音乐端口则停止启动；助手端口冲突会提示，但音乐仍能使用。
4. 音乐模型已在本地，启动启用 Hugging Face 离线模式，不下载新模型。
   Hermes 虽在本机运行，对话和图片实际调用联网模型；断网不影响已安装的音乐生成。

音乐创作
在“开始创作”页输入曲风、歌词并开始生成。歌词使用 [verse]、[chorus] 分段。
任务队列显示当前阶段、进度、已用时间与预计剩余时间，估算值会随实际进展调整。
音乐文件保存到 YuE2-Studio/data/songs/；完成后可在作品库试听、下载。
Fast 使用 AR 8-bit；声学生成部分 NAR 仍为 bf16，并非整个模型均为8-bit。
翻唱和哼唱需要的附加模型尚未安装。4-bit 已通过下述纯音乐短片段测试，默认仍保留 8-bit。
内存不足时，关闭不用的应用并重试；工作台不会主动结束其他应用。

AI 助手
1. 在“创作助手”新建会话，可关联作品，讨论歌词、曲风和封面构思。
2. 歌词/曲风建议可预览后填入创作；填入不会自动开始音乐生成，原草稿可撤销恢复。
3. 回复时可点击“停止回复”；多轮记录保存在本地，关闭页面后仍能查看。
4. 此工作台专用 Hermes 对话已禁用工具集，只做对话创作，不执行系统命令、文件修改或浏览器操作。
   不修改原 Hermes 配置，不影响你在其他入口使用 Hermes 的工具能力。
5. 封面生成后先进入候选库，点击“应用封面”才修改作品展示；可恢复上一张封面。
   应用/恢复只改变封面，不改变音频。生成失败保留描述和当前封面。
6. “连接设置”分别显示对话和图片状态。GPT Image 2 使用现有 Codex 登录，无需另填API密钥。
   可选OpenAI兼容图片服务时，需填写你自己的HTTPS地址、模型和密钥，支持PNG b64_json返回。

新版界面与播放
- 界面使用 React + TypeScript + Mantine UI 组件库，正文 13px、标题 24px；侧栏底部状态不会被播放器遮挡。
- 点击作品封面或底部右下角展开全屏播放器，带平滑展开和收起动画；Escape 收起。
  播放器收起后回到原来的页面，保留聊天草稿、滚动和筛选。
- 底部播放器切页不断播；支持拖动进度、音量、播放队列，全屏时可切换随机与循环。
- 右上角可切换深色、浅色、跟随系统，立即生效并保存。
- 关联作品和模式下拉采用应用内组件菜单，支持键盘选择和作品搜索。
- 歌词与作品信息分开；“更多作品操作”中可重命名、查看乐谱和调整高级参数。
- 作品库支持网格/列表切换、搜索、批量收录，删除前会再次确认。
- 已构建前端由原本 8765 服务提供，日常启动无需 Node 或 Vite。
- React 版本基础验收：107 项接口测试通过。本次 UI 组件库更新另通过 8 项播放器行为测试；浏览器已验证深浅主题、全屏进退场、草稿保留、键盘操作和窄屏布局。
  上一次真实音乐新测试在加载时遇到内存保护，失败记录和重试入口仍保留。

纯音乐与伴奏（2026-10-21 已安装并实测）
1. 已安装两个适配器：ar_lora_inst_v3abc.bf16（纯音乐）和 nar_lora_joint_v4.bf16（配套音频），共约210 MB。
2. 开始创作 → 高级设置 → 风格适配器，添加这两个适配器，强度均为1；编曲选择“完整编曲”。
3. 歌词只填 [instrumental]，曲风描述乐器、情绪、速度，例如 gentle piano, acoustic guitar, relaxing, 70 BPM。
4. 本机通过的测试配置：自定义 / 4bit / 8步 / CFG 1 / 低内存开启 / 10 GiB预算。
   测试通过接口将 semantic_sampling.max_tokens 限制为600，得到约24秒片段；网页普通创作尚无时长上限控件，可能生成更长音乐。
5. 作品库中《林间微光 · 纯音乐实测》可直接播放，MP3也放在本说明旁边。48kHz双声道，核心生成43.3秒，含初次模型校验共约49秒。
   这是短片段，达到长度上限后截断，不代表完整歌曲已验收。已检查音频非静音、无数字削波，并验证完整浏览器播放。
6. 首两次因整机内存压力失败；经用户同意正常退出Chrome后成功。生成前先关闭闲置重型应用，不能仅靠4bit保证任意内存状态都成功。
7. 生成带歌词人声时，在高级设置移除纯音乐适配器，再填写正常歌词与人声曲风。
8. 安装与测试记录：YuE2-Studio/logs/instrumental-install-test-report.json。
